Abstract

Spatial transcriptomics (ST) profiles gene expression in situ, but analysis remains slow and hard to reproduce because workflows span heterogeneous platforms, file formats, and toolchains and often require substantial domain expertise and programming effort. Here we present TissueAgent, a role-based multi-agent framework that turns open-ended natural-language ST requests and multimodal inputs (data, PDFs, images) into auditable, runnable workflows. A single evolving plan coordinates specialized agents and records rationales, step status, and artifact links, enabling transparent provenance and targeted replanning. TissueAgent uses self-evolving skills to distill execution traces, errors, and recovery strategies into reusable procedural knowledge, allowing workflows to improve across runs.

Across diverse ST datasets, TissueAgent generates reproducible notebooks and supports cell type and niche annotation, cell-type deconvolution, and cell–cell communication analysis, outperforming available baselines on key spatial tasks. In a reproduce-then-apply evaluation, TissueAgent reconstructs figure panels and recovers their underlying workflows from published studies using only text and images, without author-provided code, and transfers the recovered workflows to new datasets. TissueAgent also integrates external domain agents to support collaborative analysis. Together, TissueAgent enables reproducible end-to-end ST analysis and workflow reuse, helping bridge the gap between reading a spatial study and reusing its workflow in practice.

Framework

TissueAgent is modeled on how a biotech team handles an analysis request. It plans the workflow, recruits specialists, coordinates execution, checks the outputs, and returns validated results. Five orchestration agents share one plan, and a suite of internal and external expert agents does the hands-on work in Python and R. Select a role to see what it does.

Replan with targeted feedback

Autopilot

Runs the whole workflow end to end with minimal intervention. The notebook and CLI entry points always run this way.

Copilot

Pauses after planning and again after agent assignment, so you can approve the plan, edit it, or send feedback that rewinds the run to the Planner.

Method

One evolving plan

Every agent reads from and writes to the same plan. The Planner records each step's name, rationale, and expected artifacts. The Recruiter adds the assigned expert agent and its skills. The Manager records whether each step succeeded, failed, or was skipped, and links the files it produced.

The plan is a coordination protocol, a shared memory, and a provenance record at the same time. It replaces a long chat history with a compact record of what was attempted, what finished, and what failed, so errors are easier to spot before they cascade.

    Three layers of failure recovery

    Role separation lets each kind of failure be caught where it starts. Expert agents fix local errors inside their own loops. The Manager reruns a stuck step with new inputs, tools, or strategy. The Evaluator sends the run back to the Planner when the plan itself falls short.

    Evaluator replans the workflow when its outputs don't satisfy the request

    Manager reruns a failed step with revised inputs, tools, or strategy

    Expert agent resolves local execution errors, such as code bugs, in its own ReAct loop

    Self-evolving skills

    The evolving plan adapts within a run. Self-evolving skills carry lessons across runs. TissueAgent saves every run as a full trace, mines it for error–correction pairs and avoidable cost, and proposes edits to its skills and plan templates. Guardrails confine edits to natural-language knowledge files, and a reviewer can approve each one before it is committed.

    Results

    Reproducing published workflows and applying them to new data

    Papers often share data and Methods text but not runnable code. In the reproduce-then-apply setting, TissueAgent reconstructs figure panels from a published study using only the reference image, the dataset, and the text. It then transfers the recovered workflow to a new dataset.

    1. 1Reference paperFigure, data, and Methods. No author code.
    2. 2ReconstructInspect, render, compare, and repair.
    3. 3ReproduceThe figure and the code behind it.
    4. 4ApplyRun the recovered workflow on a new dataset.

    As a stress test we used panel 2E of Lohoff et al., a violin plot of gene-wise t-statistics built on a custom spatial-heterogeneity score. Recovering it means rebuilding a regression model from the Methods description. TissueAgent reproduced all 22 cell types and matched the original ordering closely (Spearman ρ ≈ 0.9). Biomni recovered 12 cell types (ρ ≈ 0.5), and SpatialAgent produced an invalid figure.

    Applied to a Stereo-seq mouse embryo from Chen et al., the recovered workflow kept the study's key patterns, such as surface ectoderm along the tissue periphery. On paired ovarian cancer data from Yeh et al., analyses rebuilt on the CosMx discovery set and transferred to the Visium validation set recovered the published findings without the agent ever seeing the target figures.

    Working with external agents

    No single agent is best at everything in biomedicine, so the Agent Registry lists external agents next to internal ones, each with its role, capabilities, and input and output schema. Once registered, an external agent is recruited like any other. In the developing human heart, TissueAgent tested whether atrial fibroblasts in the AVN/AV ring follow a distinct developmental program. The Coding Agent ran differential expression, GeneAgent interpreted the marker genes, and the Hypothesis Critic Agent weighed the combined evidence.

    Recruitment through TissueAgent preserved each external agent's standalone performance. The Recruiter correctly selected and invoked CellVoyager in all 150 workflows.

    Cell type and niche annotation

    For cell types, TissueAgent weighs the biological context, expression state, and evidence for each method, then picks one of three strategies: Harmony-based transfer from a CELLxGENE reference, a pretrained CellTypist model, or marker-based annotation with GPTCellType. For niches, it configures UTAG from the data, summarizes each niche's cell composition and location, and assigns an anatomical label with a short justification.

    TissueAgent had the best mean rank across three datasets (1.33, next best 2.92). On the developing human heart it led on macro precision, balanced accuracy, and macro F1. Its gains came from rarer cell types, which other methods tended to miss.

    Deconvolution and cell–cell communication

    For deconvolution, an LLM-based router reads the dataset's structure and picks a method from cell2location, NNLS, Tangram, CARD, SD2, and STdeconvolve. TissueAgent tunes it on pseudospot trials before fitting the full dataset. It scored highest on Visium DLPFC and tied the best method on MERFISH-derived spots, and it was the only agent to complete every run.

    For cell–cell communication, TissueAgent runs a consensus of LIANA+, stLearn, COMMOT, and decoupleR rather than trusting one method. Its top-ranked interactions were the most consistent with tissue architecture, identical across repeated runs, and produced on every attempt. In an Alzheimer's disease cohort, it also scored each top pair for literature support, and those scores tracked independent disease evidence (Spearman ρ = 0.31–0.39).
