Task and Protocol

BioFigBench-Spatial asks whether an agent can reconstruct a published spatial transcriptomics analysis from data, a reference figure, and text. Each task provides the reference panel, the corresponding data, the figure caption, and optional Methods text, while the authors' code is withheld. The agent has to recover the analysis, run it, and draw the panel.

This page lists the panels on which all three methods were run in the current snapshot.

Similarity to the Published Panels

Each reproduced image is compared with the published original on a common canvas (long edge at most 768 px, aspect ratio preserved with white padding). SSIM is the structural similarity of the grayscale images. pHash is 1 − d/64, where d is the Hamming distance between 64-bit perceptual hashes. ORB is the fraction of cross-checked feature matches (distance at most 64) among the smaller keypoint count. Higher is more similar for all three.

    How to read these numbers. The scores measure appearance only. They say nothing about whether the analysis behind a figure is correct, and they can reward a blank background or copied pixels. A missing image is left out, never scored as zero. Panels from the same paper are not independent replicates, and no significance test is claimed.
